# Texto com IA — Website sobre IA Generativa

**Tema escolhido:** Geração de texto com IA

## Descrição
Website estático com quatro páginas: introdução ao tema, ferramentas do mercado, boas práticas e questionário interativo.

## Objetivo
Apresentar de forma clara o que é a geração de texto com IA, as ferramentas disponíveis e como usá-las com responsabilidade.

## Tecnologias
HTML5, CSS3, JavaScript puro, Bootstrap 5 (CDN) e localStorage.
