  Descrição do projeto:
  Este projeto consiste no desenvolvimento de um website estático e interativo, criado com HTML5, CSS3, JavaScript e Bootstrap, colocando em prática os principais conceitos e padrões web estudados na          disciplina. O site aborda o tema Inteligência Artificial Generativa, com foco na geração de textos por IA, apresentando suas funcionalidades, principais ferramentas, aplicações e impactos no cotidiano.      Além disso, conta com recursos de armazenamento local de dados e um questionário interativo, proporcionando uma experiência dinâmica, educativa e intuitiva para os usuários.

  Tecnologias utilizadas:
  - Chatgpt, para a elaboração dos prompts;
  - Cloude code, para o auxílio na criação do site;
